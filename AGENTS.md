# KODA-Coding-Agent

KODA is a terminal coding agent: a Python backend (`koda/`, `coding_agent/`) — LangGraph/deepagents-based adapters, bridge, sessions, MCP — driven by a TypeScript + Ink TUI (`koda-ink/`) over a stdio NDJSON protocol. Install via `uv pip install -e ".[all]"`.
